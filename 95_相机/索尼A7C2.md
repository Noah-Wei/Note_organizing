# 索尼 A7C2

## 📷 模式转盘各档位说明（MODE DIAL）

| 档位                | 名称（中文）                         | 名称（英文）        | 功能说明                                                     |
| ------------------- | ------------------------------------ | ------------------- | ------------------------------------------------------------ |
| **Auto**            | 全自动模式                           | Intelligent Auto    | 相机自动选择场景并设置曝光参数，适合新手拍摄，无需调节       |
| **P**               | 程序自动曝光                         | Program Auto        | 相机会自动设置光圈和快门速度，但用户可以调整 ISO、白平衡等   |
| **A**               | 光圈优先                             | Aperture Priority   | 用户手动设置光圈，相机会自动设置快门速度，用于控制景深       |
| **S**               | 快门优先                             | Shutter Priority    | 用户手动设置快门速度，相机自动设置光圈，用于拍摄运动物体或夜景 |
| **M**               | 手动曝光模式                         | Manual Exposure     | 用户全手动控制快门速度和光圈，适合专业拍摄或需要特殊曝光的情况 |
| **MR**              | 存储调用模式                         | Memory Recall       | 快速调用用户预设的拍摄设置（需提前在菜单中设置）             |
| **Movie**           | 视频拍摄模式                         | Movie               | 进入视频录制模式，显示视频相关设置如帧率、分辨率等           |
| **S&Q**             | 慢动作/快动作                        | Slow & Quick Motion | 拍摄慢动作或快动作视频，用于制作特效影片（需设置帧率）       |
| **SCN**             | 场景模式                             | Scene Selection     | 提供各种场景模式（如人像、风景、夜景等），相机自动优化设置   |
| **★/Creative Look** | 创意外观模式（取代以前的“效果”模式） | Creative Look       | 可设置预设的色彩风格和氛围，例如“标准”、“鲜艳”、“黑白”等     |

------

### 🎥 视频用户特别注意：

- 如果你经常拍视频，可以优先使用 **Movie（电影模式）** 和 **S&Q（慢快动作）**。
- A7C2 支持 4K 60fps（裁切） 和 4K 30fps（全宽），并且具备 10-bit 4:2:2 色彩采样，适合高级视频剪辑。
- 配合 **Picture Profile**（如 S-Log3, Cine2, HLG）使用，可获得更高的动态范围。

## 📺 DISP 按钮的功能详解

按下 **DISP 按钮**（默认在后拨盘或 Fn 菜单中），可以在不同的显示界面之间循环切换，帮助你在拍摄时查看不同的信息。

### 🔄 常见显示模式（可自定义启用或关闭）：

| 显示模式                     | 说明                                                 |
| ---------------------------- | ---------------------------------------------------- |
| **图像+参数信息**            | 显示实时画面 + 快门、光圈、ISO 等完整参数            |
| **最简画面（干净屏）**       | 只显示画面，隐藏所有参数，适合专注构图或录像时       |
| **直方图模式**               | 在画面上显示实时曝光直方图，帮助控制曝光             |
| **水平仪**                   | 显示电子水平仪，辅助你保持画面水平                   |
| **取景器风格（带模拟曝光）** | 更接近最终照片效果的显示方式                         |
| **实时参数监控**             | 显示详细拍摄设置和实时值，如白平衡、测光、对焦模式等 |



**安全快门 = 在当前焦距下，为了防止手抖导致的画面模糊，建议使用的**最慢快门速度**。

### 🔢 安全快门的基本公式：

```
复制编辑
安全快门 ≈ 1 / 焦距（单位：秒）
```

- 举例：
  - 使用 **50mm** 镜头，建议快门速度不慢于 **1/50 秒**
  - 使用 **200mm** 镜头，建议不慢于 **1/200 秒**

> ⚠️ 全画幅相机下直接用焦距；APS-C 画幅需要 ×1.5（焦距裁切因素）









在M档下，ISO 设置为自动 ISO时，可以使用曝光补偿。ISO 设置为手动固定值时， 无法使用曝光补偿

“AF 开启”中的 **AF** 是 “Auto Focus”（自动对焦）的缩写。

AV 模式（Aperture Priority）= 光圈优先，在索尼相机上叫做 **A 模式（Aperture Priority）**，跟 AV 是一样的概念。

TV 模式（Time Value）= 快门优先，在索尼相机上叫做 **S 模式（Shutter Priority）**，和 TV 同义。
